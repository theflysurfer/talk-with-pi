## Parent

#1 (spec Pont vocal Pi)

## What to build

L'extension pi-voice-bridge se charge dans la session Pi vivante, expose un serveur WebSocket local (127.0.0.1, port libre, token dédié), gère la commande `/voice on|off|status` et le verrou `active.json` (sessionFile, pid, since). Un client wscat se connecte, fait `hello` avec le token, reçoit `ready`, et `ping→pong`. Une seule session porte la voix (verrou, périmé si pid mort, auto-réactivation au session_start).

## Acceptance criteria

- [ ] `/voice on` dans une session crée le verrou `~/.pi/voice-bridge/active.json` et notifie la précédente session voix
- [ ] wscat se connecte au WS, `hello` avec token valide → `ready` ; token invalide → connexion fermée
- [ ] `ping` → `pong` ; un seul client à la fois (nouveau remplace l'ancien)
- [ ] WS lié à 127.0.0.1 uniquement, jamais exposé sur le mesh
- [ ] Au `session_start`, si le fichier de session correspond au verrou, la session se réactive

## Blocked by

None (can start immediately).

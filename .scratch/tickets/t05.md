## What to build

Descripteur (audio-description par petit modèle) : appeler `ctx.modelRegistry.find/complète` hors session (haiku-4-5 par défaut), décrire ce qui n'est pas lisible à l'oral (bloc de code, diff, résultat d'outil, burst d'outils). Gabarit immédiat, descripteur en parallèle (délai 2,5 s), `replaces` s'il revient avant lecture, budget 60 calls/h, `allowCode:false` pour ne jamais filer de code. Ne consomme ni contexte ni run Pi.

## Acceptance criteria

- [ ] Un résultat d'outil produit une description (ex. « deux tests échouent dans auth ») si le descripteur revient à temps
- [ ] Délai max 2,5 s ; au-delà, le gabarit seul suffit
- [ ] `replaces` : le descripteur remplace le gabarit non encore lu
- [ ] `allowCode:false` → jamais de code envoyé au fournisseur
- [ ] Budget : plafond d'appels/h ; au-delà, gabarits seuls

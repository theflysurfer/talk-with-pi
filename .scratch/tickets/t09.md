## What to build

Client Android : Chrome PWA (push-to-talk) qui rejoint le serveur WS de l'extension via le relais VPS, pousse l'audio micro, lit l'audio TTS retour, barge-in local (coupe la lecture quand on appuie parle), reprise réseau 4G/wi-fi. La conversation de bout en bout depuis le Pixel fonctionne.

## Acceptance criteria

- [ ] Conversation de bout en bout depuis le Pixel en 4G (parole → transcription → réponse Pi → voix)
- [ ] Push-to-talk : tenir pour parler, relâcher pour envoyer
- [ ] Barge-in local : coupe la lecture TTS, ne tue pas le run Pi
- [ ] Reprise réseau (4G↔wi-fi) sans re-ouvrir manuellement

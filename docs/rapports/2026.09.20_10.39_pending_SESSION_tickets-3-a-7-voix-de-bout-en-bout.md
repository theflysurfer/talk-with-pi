## Decisions

1. **STT/TTS par les proxys Paseo** (ADR 0005) — **Choix** : `:8791` (Cartesia) et `:8792` (Groq)
   au lieu de Pi Daemon `/stt` `/tts` + edge-tts. **Rationale** : les proxys existaient, étaient up,
   registrés LSM et `auto_start`, tandis que les endpoints du plan n'existaient pas sur ce poste.
   **Alternative rejetée** : monter edge-tts et Pi Daemon pour respecter le plan — deux composants à
   maintenir pour un service déjà rendu.
2. **Deux voix par paramètre de requête** — **Choix** : ajouter `voice` au proxy TTS plutôt qu'un
   second service. **Rationale** : défaut inchangé donc non-breaking pour Paseo. **Alternative
   rejetée** : un deuxième proxy sur un autre port (doublon de code et de lifecycle).
3. **`allowCode:false` par défaut** — le descripteur ne voit jamais un bloc de code ; les blocs
   fencés d'un résultat d'outil deviennent `(code retiré)` avant l'envoi au fournisseur.
4. **Le pont n'est pas un service LSM** — il vit dans la session Pi (verrou mono-session) ; seul le
   port 8766 est réservé dans la carte des ports.

## Problems

1. **L'extension n'aurait jamais chargé** — **Symptôme** : rien, justement. **Cause** :
   `import { VoiceBridge } from "./server"` sans l'extension `.ts` ; le loader ESM rend
   `ERR_MODULE_NOT_FOUND`. **Solution** : imports en `./server.ts` + `allowImportingTsExtensions`.
   **Prévention** : posé dans `AGENTS.md`.
2. **La dictée Paseo était cassée en silence** — **Symptôme** : transcription vide, parfois
   connexion fermée sans réponse. **Cause** : le proxy STT appelait Groq avec l'UA `python-urllib`,
   rejeté par Cloudflare (« error code: 1010 »). **Solution** : UA explicite (`STT_USER_AGENT`).
   **Prévention** : le `/health` du proxy ne teste que le port — proposé à Julien de le durcir.
3. **Un `/health` menteur** — **Symptôme** : LSM affichait `pi-daemon` running. **Cause** : un
   Datasette lancé à la main squattait :8790 et répondait 404 sur `/health`. **Solution** : port
   libéré, Datasette registré sur :8794. **Prévention** : règle dans `AGENTS.md` et l'ADR 0005.
4. **Faux négatif de vérification** — **Symptôme** : `pi -p "/voice on"` ne créait pas le verrou,
   j'ai failli conclure que l'extension ne chargeait pas. **Cause** : en mode `--print`, une
   commande slash part au modèle comme du texte. **Solution** : mode RPC. **Prévention** :
   `AGENTS.md`.
5. **Une clé Groq invisible du scrubber** — **Symptôme** : `scan` rendait `findings=0` sur une clé
   `gsk_…` présente dans un transcript. **Cause** : aucune règle Groq dans `_RULESPECS`.
   **Solution** : règle `groq-api-key` + test (repo Secret Scrubber, commit 0a577fa).
   **Prévention** : la règle capte désormais les futures fuites.
